# NAVEGACIÓN BÁSICA CON PROTECCIÓN

## Objetivo

Implementar la navegacion a través de rutas protegidas

## Decripción

1. Home (/) Página pública con el boton de Login
2. Perfil (/profile) Página protegida con información del usuario
3. DashBoard (/DashBoard) Página protegida con estadística

## Requisitos

1. Vite
2. React Router Dom v7
3. Simular el uso de un token que valide el login 
(guaradando en el LocalStorage)
4. Página de Erroes gestionados por nosotros
