# Proyecto de pokemon con uso de React Router v7

Se pretende realizar un proyecto que utilice las siguientes tecnologías

>- React Router Dom en su version 7
>- Contextos globales
>- Libreria Sonner para notificaciones
>- Estilado con tailwind CSS

El Scafolding que se va a utilizar es el siguiente:

```text
src/
├── components/              
│   ├── Navbar.jsx           
│
├── context/             
│   ├── PokemonContext.jsx   
│
├── layout/                  
│   ├── RootLayout.jsx      
│
├── pages/                 
│   ├── Home.jsx             
│   ├── PokemonDetails.jsx    
│   ├── Favorites.jsx        
│
├── routes/                
│   ├── Router.jsx        
│   ├── Paths.jsx          
│
├── app.jsx                  
├── main.jsx 

```
